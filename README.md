# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

面向烟花燃放编排师的彩排脚本工具：记录节目段落、烟花型号、口径、发射角度、持续时间、安全距离与音乐锚点，点火时间由段落顺序自动推导，不再逐条手填。

## 功能

- **顺序可调**：每段提供 ↑ / ↓ 换位。换位后自动从改动段到下一处音乐锚点之间重新排点，锚点本身留在原时刻。
- **冲突提示**：若重排把某个点火窗口推到锚点之后，页面标出「前移段」（换位提前的段落）与「受阻段」（窗口越过锚点的段落），并给出具体窗口与锚点时刻。
- **预览冻结**：存在冲突时，时间轴预览停留在前一可完整播放的版本；解除冲突后自动恢复为最新版本。预览支持播放 / 暂停 / 复位与 1× / 8× 速度。
- **另存演出值**：确认脚本后另存为当晚演出值快照（追加保存，旧快照不被覆盖）；再次打开页面自动从最新演出值继续彩排。
- **草稿自动保存**：彩排过程中的每次修改自动存入草稿，与演出值快照互不干扰，旧草稿不被另存操作覆盖，可随时载入。

## 本地存档

使用 localStorage，键名：

- `hxy62008.fireworks.draft.v1`：自动保存的彩排草稿（含上一份可完整播放的脚本）
- `hxy62008.fireworks.shows.v1`：确认后另存的当晚演出值快照列表
