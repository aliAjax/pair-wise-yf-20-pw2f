# hxyfront-62008 烟花燃放脚本编排

面向烟花燃放编排师的彩排工具：用音乐锚点把整场切成排布块，段落可自由换位，点火时间自动排定。

## 核心规则

- **锚点固定**：音乐锚点（如进鼓、重拍、Drop）钉在原时刻，换位不移动锚点。
- **自动排点**：块内段落首尾相接。换位后，从改动段到下一处音乐锚点之间的段落重新排点火窗口，无需逐条手填时间。
- **跨锚点冲突阻断**：若某次换位把某段的点火窗口推到锚点之后，页面用红色横幅标出
  - **前移段**：被移动的段落（琥珀色高亮）
  - **受阻段**：越界的段落（红色高亮），并给出其结束时刻与锚点时刻
  - 本次换位**不落盘**，时间轴与预览停在上一个可完整播放的版本。
  - 编辑段落时长、新增段落/锚点时同样校验。
- **草稿 / 演出值双版本**
  - 草稿自动保存到 localStorage（`hxyfront-62008/rehearsal/v1`）。
  - “确认脚本”把当前草稿另存为**当晚演出值**只读快照，并自动从演出值复制出下一场彩排；旧草稿与旧演出值均不被覆盖。
  - 再次打开页面默认进入最近一次彩排（即从演出值续排的那份）。
  - “场次与版本”可查看任意草稿/演出值，或从历史演出值“从此续排”。

## 其他功能

- 整场节目时间轴预览（播放头、锚点竖线、越界段红色斜纹）
- 燃放点位平面图（A–E 点位，播放时实时点亮）
- 型号清单（按型号/口径汇总数量与最大安全距离）
- 冲突提示计数、最近安全距离指标

## 技术栈

React 19 + Vite + TypeScript，无额外运行时依赖。

- 纯排布逻辑：`src/schedule.ts`（`computeSchedule` / `moveSegment` / `findProblems`）
- 本地持久化：`src/storage.ts`
